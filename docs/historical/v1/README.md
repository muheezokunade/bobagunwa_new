**Status: historical reference only. Nothing in this folder describes the current application or counts as evidence that it works.**

`muheezokunade/bobagunwa` at commit `945ffb5` on 16 November 2026. They document the earlier

research. The current platform (Laravel 13 / MariaDB 11.4 for Namecheap) reuses its confirmed
requirements, decisions and acceptance scenarios; see `docs/02-source-reference-inventory.md`
for exactly what was reused, corrected or superseded.
