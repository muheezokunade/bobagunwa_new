# Route inventory

_Generated by `php artisan boba:docs:reference` on 2026-11-16 from the live router — do not edit by hand._

Access is enforced server-side by middleware on every route and again inside the services for financial and membership decisions; menus only hide links. Behaviour, validation, states and acceptance criteria for each workflow are in the procedure documents and the tests named in [03-requirements-traceability.md](03-requirements-traceability.md). Every authenticated response is `Cache-Control: no-store` and `noindex`.
